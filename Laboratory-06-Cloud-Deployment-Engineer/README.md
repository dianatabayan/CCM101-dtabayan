# Laboratory 06: Cloud Deployment Engineer

## Mission Overview
Deployed a two-tier Nextcloud private cloud storage system for CloudNova
Technologies using Docker Compose, with MariaDB as the database tier.

## Objectives
- Document multi-tier architecture
- Write a docker-compose.yml for a Nextcloud and MariaDB stack
- Deploy, access, and tear down the stack

## Commands Executed
- `mkdir nextcloud-deployment`
- `nano docker-compose.yml`
- `docker-compose up -d`
- `docker-compose ps`
- `docker-compose down`

## Skills Learned
- Writing YAML configuration files
- Deploying multi-container applications
- Connecting containers with environment variables
- Documenting infrastructure
