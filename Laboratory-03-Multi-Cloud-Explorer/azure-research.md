# Microsoft Azure Research

## Brief Overview

**Microsoft Azure** is Microsoft's cloud computing platform. It allows users and businesses to **store data, run applications, use virtual computers, and access cloud services through the internet**.

Azure is widely used for **AI, databases, data analytics, and business applications**. It also works well with Microsoft products such as Windows and Microsoft 365.

## Global Infrastructure

Azure has data centers around the world organized into:

* **Regions** – geographic areas containing Azure data centers.
* **Availability Zones** – separate locations within a region that help keep applications running.
* **Geographies** – areas containing one or more regions, often used for data and legal requirements.

This large global infrastructure helps Azure provide **reliable and fast services** to users in different locations.

## Cloud Management Console

The **Azure Portal** is the website used to manage Azure resources. Users can:

* Create and manage cloud services
* Manage virtual machines and databases
* Monitor resources
* Check costs and billing
* Manage users and permissions
* Choose Azure regions

The portal provides a simple way to manage different Azure services in one place.

## Four Core Services

| Service                            | Purpose                           |
| ---------------------------------- | --------------------------------- |
| **Azure Virtual Machines**         | Runs virtual computers            |
| **Azure Blob Storage**             | Stores files and data             |
| **Azure SQL Database**             | Manages relational databases      |
| **Azure Kubernetes Service (AKS)** | Runs container-based applications |

### Azure Virtual Machines

Provides virtual computers that can run **websites, applications, and other programs**.

### Azure Blob Storage

Stores files such as **images, videos, documents, and backups**.

### Azure SQL Database

A managed database service used to **store and organize information** without managing the physical database server.

### Azure Kubernetes Service (AKS)

**AKS** helps users run and manage applications using **containers and Kubernetes**.

## Three Advantages

1. **Strong Microsoft Integration** – Azure works well with Microsoft products such as Windows Server, Microsoft 365, and other business tools.
2. **Large Global Infrastructure** – Azure has many regions around the world, helping businesses serve users in different locations.
3. **Strong Security and Reliability** – Azure provides security, backup, and availability features to help protect business applications and data.

## Typical Enterprise Uses

Azure is commonly used for:

* **Business applications**
* **AI and machine learning**
* **Data analytics**
* **Websites and cloud applications**
* **Database management**
* **File storage and backup**
* **Microsoft-based enterprise systems**
