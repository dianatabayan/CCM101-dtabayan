# Checkpoint 3 – Compare the Major Cloud Platforms

## Cloud Platform Comparison

| Category                | Amazon Web Services (AWS) | Microsoft Azure               | Google Cloud Platform (GCP)                 |
| ----------------------- | ------------------------- | ----------------------------- | ------------------------------------------- |
| **Launch Year**         | 2006                      | 2010                          | 2011                                        |
| **Compute Service**     | Amazon EC2                | Azure Virtual Machines        | Compute Engine                              |
| **Storage Service**     | Amazon S3                 | Azure Blob Storage            | Cloud Storage                               |
| **Networking Service**  | Amazon VPC                | Azure Virtual Network         | Google Cloud VPC                            |
| **Identity Service**    | AWS IAM                   | Microsoft Entra ID            | Cloud IAM                                   |
| **Primary Strength**    | Wide range of services    | Microsoft integration         | AI, data analytics, and Kubernetes          |
| **Ideal Organizations** | Businesses and startups   | Microsoft-based organizations | AI, research, and data-driven organizations |

### Questions

**1. Which cloud provider offers the broadest range of services?**

**AWS** offers the broadest range of cloud services, including computing, storage, databases, networking, security, and AI.

**2. Which provider best integrates with Microsoft technologies?**

**Microsoft Azure** provides the best integration with Microsoft products such as **Windows Server, Microsoft 365, and Microsoft Entra ID**.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**

**Google Cloud** is especially strong in **AI, data analytics, and Kubernetes**. Google created Kubernetes and provides **GKE**, while **Vertex AI** supports AI and machine learning.

**4. Which cloud platform would you personally choose and why?**

I would choose **Google Cloud** because it has strong **AI, data analytics, and Kubernetes services**. It is also a good platform for learning modern cloud technologies.
