# GCP Research – Google Cloud

## Brief Overview

**Google Cloud Platform (GCP)** is Google's cloud computing platform, launched in **2011**. It allows users and businesses to **store data, run applications, and use computing resources through the internet**. GCP is especially known for **AI, machine learning, data analytics, and Kubernetes**.

## Global Infrastructure

GCP's infrastructure is organized into:

* **Regions** – geographic areas containing cloud data centers.
* **Zones** – separate locations within a region where resources run.
* **Google Private Network** – Google's network that connects its data centers, providing fast and reliable connections.

## Cloud Management Console

The **Google Cloud Console** is a web-based tool for managing GCP resources. It includes:

* **Projects** – organize cloud resources.
* **IAM** – manages user access and permissions.
* **Billing** – monitors cloud costs.
* **Cloud Shell** – provides a browser-based command line.
* **Terraform** – helps automate cloud resource setup.

## Four Core Services

| Service            | Purpose                           |
| ------------------ | --------------------------------- |
| **Compute Engine** | Runs virtual machines             |
| **Cloud Storage**  | Stores files and data             |
| **Cloud SQL**      | Manages relational databases      |
| **GKE**            | Runs container-based applications |

**Compute Engine** provides virtual computers for websites and applications.
**Cloud Storage** stores files such as photos, videos, and backups.
**Cloud SQL** provides managed databases such as MySQL and PostgreSQL.
**GKE** manages applications running in containers and Kubernetes.

## Three Advantages

1. **AI and Data Analytics** – Tools like BigQuery and Vertex AI help organizations analyze data and build AI applications.
2. **Strong Kubernetes Support** – Google created Kubernetes, making GKE a strong choice for containerized applications.
3. **Fast Global Network** – Google's private network provides fast and reliable connections between locations.

## Typical Enterprise Uses

GCP is commonly used for:

* **Big data and business analytics**
* **AI and machine learning**
* **Web and cloud applications**
* **Gaming and video streaming**
* **Startups and research**
* **Data storage and backup**
