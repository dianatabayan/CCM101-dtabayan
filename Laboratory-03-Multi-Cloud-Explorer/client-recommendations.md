# Checkpoint 4 – Cloud Platform Recommendation Challenge

## Client A – Startup Company

**Recommended Platform: Amazon Web Services (AWS)**

AWS is a good choice because it offers many services and flexible options for a startup. It can also scale as the mobile application gets more users.

**Possible services:**

* **Amazon EC2** – runs the application
* **Amazon S3** – stores files and data
* **Amazon RDS** – manages the database

---

## Client B – University

**Recommended Platform: Microsoft Azure**

Azure is a good choice because the university already uses **Windows Server, Microsoft 365, and Active Directory**. Azure works well with Microsoft products and can make the migration easier.

**Possible services:**

* **Azure Virtual Machines** – runs Windows systems
* **Azure SQL Database** – manages databases
* **Microsoft Entra ID** – manages users and access

---

## Client C – AI Research Company

**Recommended Platform: Google Cloud Platform (GCP)**

GCP is a strong choice because the company focuses on **AI and Machine Learning**. Google provides powerful tools for AI, data analysis, and research.

**Possible services:**

* **Vertex AI** – develops AI and ML models
* **Compute Engine** – provides computing power
* **BigQuery** – analyzes large datasets

---

## Client D – Global E-Commerce Company

**Recommended Platform: Amazon Web Services (AWS)**

AWS is a good choice because the company serves customers worldwide and needs **scalable and reliable infrastructure**. AWS can handle large amounts of traffic and support applications in different regions.

**Possible services:**

* **Amazon EC2** – runs the e-commerce application
* **Amazon S3** – stores product images and files
* **Amazon RDS** – manages customer and product data
* **Amazon CloudFront** – delivers content quickly to users

---

# Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement        | Recommended Platform | Justification                                                                     |
| --------------------------- | -------------------- | --------------------------------------------------------------------------------- |
| **Startup Company**         | **AWS**              | Offers many services and can scale as the startup grows.                          |
| **Enterprise Organization** | **Azure**            | Provides strong features for large organizations.                                 |
| **Microsoft Environment**   | **Azure**            | Works well with Windows Server, Microsoft 365, and other Microsoft products.      |
| **AI / Machine Learning**   | **GCP**              | Provides strong AI tools such as Vertex AI and data analytics services.           |
| **Kubernetes Deployment**   | **GCP**              | Google created Kubernetes, and GKE provides strong Kubernetes support.            |
| **Global Web Application**  | **AWS**              | Has a large global infrastructure and supports highly available web applications. |
