# AWS Research – Amazon Web Services

## Brief Overview

**Amazon Web Services (AWS)** is a cloud computing platform provided by Amazon. It allows users and businesses to **store data, run applications, use virtual computers, and access different cloud services through the internet**.

AWS is one of the largest cloud platforms in the world. It is used by **businesses, schools, startups, and large organizations**.

## Global Infrastructure

AWS has data centers around the world organized into:

* **Regions** – large geographic areas where AWS has cloud infrastructure.
* **Availability Zones (AZs)** – separate locations within a region that help keep applications available.
* **Edge Locations** – locations closer to users that help deliver content faster.

This global infrastructure helps AWS provide **reliable and fast services** to users around the world.

## Cloud Management Console

The **AWS Management Console** is a website used to manage AWS services. It allows users to:

* Create and manage cloud resources
* Choose regions for their resources
* Monitor services and usage
* Check billing and costs
* Manage users and security

The console makes it easier to control AWS services from one place.

## Four Core Services

| Service        | Purpose                                  |
| -------------- | ---------------------------------------- |
| **Amazon EC2** | Runs virtual computers                   |
| **Amazon S3**  | Stores files and data                    |
| **Amazon RDS** | Manages relational databases             |
| **Amazon EKS** | Runs and manages Kubernetes applications |

### Amazon EC2

**Amazon Elastic Compute Cloud (EC2)** provides virtual computers that can run **websites, applications, and other programs**.

### Amazon S3

**Amazon Simple Storage Service (S3)** is used to store files such as **photos, videos, documents, and backups**.

### Amazon RDS

**Amazon Relational Database Service (RDS)** is a managed database service that makes it easier to create, operate, and maintain databases.

### Amazon EKS

**Amazon Elastic Kubernetes Service (EKS)** is used to run and manage applications using **Kubernetes and containers**.

## Three Advantages

1. **Wide Range of Services** – AWS provides many services for computing, storage, databases, networking, security, AI, and more.
2. **Global Infrastructure** – AWS has many Regions and Availability Zones, allowing businesses to serve customers around the world.
3. **Scalability and Flexibility** – Businesses can increase or decrease their cloud resources depending on their needs.

## Typical Enterprise Uses

AWS is commonly used for:

* **Websites and web applications**
* **Data storage and backup**
* **Business and data analytics**
* **AI and machine learning**
* **Online gaming and media**
* **Business databases**
* **Cloud-based applications**
