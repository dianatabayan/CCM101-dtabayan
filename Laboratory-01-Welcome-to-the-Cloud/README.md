# Laboratory Activity 1 – Mission 1: Welcome to the Cloud

## Mission Overview

This activity served as an introduction to cloud computing environments and Linux system administration. As a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies, I learned how to work within a Linux-based cloud environment, document technical tasks professionally, and maintain a version-controlled portfolio using GitHub.

## Objectives

- Access and navigate a cloud-based Linux environment using KillerCoda
- Explore essential Linux commands and system navigation techniques
- Gather and analyze basic system information
- Organize files and directories using Linux commands
- Create and manage a professional GitHub repository
- Document technical activities using Markdown

## Activities Performed

- Launched an Ubuntu Linux Playground environment on KillerCoda
- Created a new user account and configured appropriate permissions
- Verified user information, working directory, and hostname
- Collected system details, including Linux distribution, kernel version, CPU, memory, and disk space
- Created and organized a directory structure for project documentation
- Developed and viewed Markdown files such as `about-me.md` and `system-information.md`
- Created and configured a public GitHub repository for cloud computing coursework
- Structured the repository as a professional Cloud Computing Portfolio
- Documented all activities, observations, and outputs using Markdown

## Linux Commands Used

`whoami`, `pwd`, `hostname`, `cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`, `mkdir`, `nano`, `cat`, `ls`, `git clone`, `git add`, `git commit`, `git push`

## Skills Learned

- Linux system navigation and command-line operations
- User account creation and privilege management
- System information gathering and analysis
- File and directory management in Linux
- Technical documentation using Markdown
- Git and GitHub version control workflows
- Repository organization and portfolio development
