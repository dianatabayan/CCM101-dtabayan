# Mission Reflection

Doing this lab really helped me understand how cloud infrastructure works, not just in theory but by actually seeing it in a real Linux environment.

If I had to pick the most important component, I'd say networking. The reason is pretty simple even if a server has a lot of CPU, RAM, and storage, none of that is useful if people can't actually connect to it. During the lab, I saw this when I looked at the network interfaces and IP addresses using `ip a`. It made me realize that networking is basically what connects everything else together. Of course, that doesn't mean the other components aren't important too. Compute, storage, and networking all need to work together for the whole system to actually be useful.

I also learned a lot about why Linux is used so much in cloud computing. It's stable, secure, and lightweight, which is probably why big providers like AWS, Azure, and Google Cloud all support it. What I liked most was using the command line to actually explore the server myself instead of just reading about it. Commands like `lscpu`, `free -h`, `df -h`, and `ip a` let me check the CPU, memory, storage, and network setup directly, which made everything feel a lot more real.

Another thing I took away from this lab is how important documentation is. Before this, I didn't really think about how much writing is involved in IT work, but documenting my findings actually helped me understand the material better. It also made me realize that documentation isn't just for other people to read later it also helps you organize your own thoughts while you're working.

In terms of skills, I think I learned the most about how to inspect a Linux server and connect what I found to real cloud concepts like compute, storage, and networking. I also got more comfortable comparing AWS, Azure, and Google Cloud, since I had to look up what each provider offers and how they're similar or different. I practiced using Git and GitHub more creating files, committing changes, setting up my Git identity, and pushing everything to my repository.

I think this mission made my GitHub portfolio a lot stronger. It now has a full cloud computing lab project with documentation, research, a provider comparison, and this reflection. I feel like it shows that I can actually explore a system, connect it to real concepts, and explain what I learned in a clear way.
